# 宝宝照护日记

一个无需安装的婴儿照护记录网页。数据始终保存在本机浏览器，也可以同步到自己的 GitHub 私有仓库。

## 手机在线使用（GitHub Pages）

打开部署后的 GitHub Pages 地址即可直接记录。未开启云同步时，数据只保存在当前手机浏览器。

## GitHub 私有仓库多端同步

1. 在同一个 GitHub 账号下新建名为 `baby-care-data` 的 **Private** 仓库
2. 创建 Fine-grained personal access token，只允许访问该仓库，并将 `Contents` 权限设为 `Read and write`
3. 打开网页的“数据管理 → GitHub 私有云同步”
4. 粘贴仓库访问令牌；网页已固定使用 `poplarorz-ui/baby-care-data`，无需再填写用户名和仓库名
5. 在其他设备填写同一套配置，以后新增、修改和删除都会自动合并

记录以明文 JSON 保存在私有数据仓库中。访问令牌只保存在各设备浏览器中，不会写入网页代码或公开仓库。请勿把令牌发送给他人。

第一次在手机使用时：

1. 在电脑页面点击“数据管理 → 导出备份”，得到 `宝宝照护记录.json`
2. 把这个 JSON 文件发送到手机
3. 用手机打开在线页面，点击“数据管理 → 导入历史数据”并选择该文件
4. 也可以开启上面的私有仓库同步，之后无需再手动导入导出

建议隔几天在手机上点一次“导出备份”。清理浏览器网站数据、换浏览器或换手机会清除该浏览器中的记录，可用最近导出的 JSON 恢复。

## 使用

在 PowerShell 中运行：

```powershell
.\start-local.ps1
```

然后打开 `http://127.0.0.1:4174/`。通过这个本地地址使用时，每次导出都会覆盖项目目录中的 `宝宝照护记录.json`。

手机查看：让手机和电脑连接同一个 Wi-Fi，保持本地服务运行，然后在手机浏览器打开启动窗口中显示的“手机同一 Wi-Fi 可访问”地址。首次启动若 Windows 防火墙询问，只允许“专用网络”即可。

手机浏览器与电脑浏览器的数据空间相互独立。需要把电脑历史带到手机时，将 `宝宝照护记录.json` 发送到手机，再通过页面的“导入历史数据”导入；之后手机端也可以正常记录。在线版导出时，文件会保存到手机的下载目录。

不建议直接把整个文件夹拷到手机打开：部分手机浏览器会限制本地网页脚本、历史保存和文件覆盖。即使能打开，固定覆盖备份功能也不能保证可用。

直接双击 `index.html` 仍可使用，但由于浏览器安全限制，此时导出会走普通下载。

## 功能

- 记录母乳 / 奶粉的时间与奶量
- 记录大便、小便的时间和大 / 中 / 小量
- 记录兰光开始、结束时间，支持正在计时和按疗程累计
- 记录洗澡时间，可选填写时长、水温和备注
- 显示宝宝姓名、出生时间并自动计算年龄
- 记录身高、体重和黄疸数值，首页展示最近一次结果
- 统计看板按天展示身高、体重、平均吃奶量、大小便次数和黄疸数值走势
- 记录疫苗名称、针次和下次预约日期，并显示距离下次疫苗的天数
- 自动计算同类记录间隔
- 按每次吃奶后 3 小时显示实时倒计时与预计下次时间
- 自动统计每天次数、奶量、排泄量分布和兰光疗程累计时长
- 使用 0–24 点共用横轴展示吃奶、排泄时间点和兰光持续时段
- 按日期查看和筛选时间线
- 数据自动保存在浏览器，每次打开自动恢复历史记录
- 每次新增、修改或删除后都会立即写入浏览器存储，无需手动同步
- 本地服务运行时，会在后台自动覆盖更新 `宝宝照护记录.json`
- 支持导出 JSON 备份、再次导入并与现有历史自动合并去重
- 通过本地服务导出时固定覆盖当前目录的 `宝宝照护记录.json`
- 宝宝档案、喂养、排泄、兰光、洗澡、成长、黄疸和疫苗记录统一保存在同一个 JSON
- GitHub 私有仓库多端同步，自动合并明文 JSON 记录
- 通过 GitHub Pages 在线使用时，手动导出采用文件下载
